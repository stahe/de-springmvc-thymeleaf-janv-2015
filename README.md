## Überblick

Ziel dieses Dokuments ist es, anhand von Beispielen die grundlegenden Konzepte von **Spring MVC** vorzustellen, einem Java-Web-Framework, das auf dem **MVC-Modell (Model–View–Controller)** basiert.

Spring MVC ist Teil des **Spring Framework**-Ökosystems und bietet ein strukturiertes Framework für die Entwicklung robuster und leicht zu verwaltender Java-Webanwendungen.

Der Kurs stellt außerdem **Thymeleaf** vor, eine moderne und leistungsstarke Rendering-Engine, die sich besonders gut in Spring MVC integrieren lässt.

## Zielgruppe

Dieser Kurs richtet sich an Leser mit **guten Java-Kenntnissen**.

**Es sind keine Vorkenntnisse in der Webprogrammierung erforderlich**, da die Konzepte schrittweise eingeführt werden.

## Umfang des Dokuments

Obwohl dieses Dokument relativ detailliert ist, erhebt es keinen Anspruch auf Vollständigkeit.
Spring ist ein umfangreiches Framework, das aus zahlreichen Komponenten und Erweiterungen besteht.

Das Dokument ist so konzipiert, dass es **ohne Computer gelesen werden kann**, was das Vorhandensein zahlreicher **Screenshots** erklärt.
